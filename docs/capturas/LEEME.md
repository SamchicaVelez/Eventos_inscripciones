# Capturas de pantalla para el README

Con la aplicación corriendo (`./mvnw spring-boot:run`), toma estas siete capturas
y guárdalas en esta carpeta con **exactamente** estos nombres. El README ya las enlaza.

| Archivo | Qué mostrar |
|---|---|
| `01-eventos.png` | Lista de eventos con las barras de cupo, y una fila desplegada |
| `02-formulario-evento.png` | Formulario "Nuevo evento" (ideal: con un mensaje de error visible) |
| `03-agenda.png` | Agenda del *Taller de Java* con sus 2 actividades |
| `04-inscripciones.png` | Inscripciones del *Taller de Java* (3 inscritos y 2 en espera) |
| `05-asistencia.png` | Asistencia de la *Sesión 1* del evento finalizado, con casillas marcadas |
| `06-estadisticas.png` | Estadísticas con las barras de ocupación y asistencia |
| `07-certificados.png` | Certificados del evento finalizado (Elena y Andrés con "Descargar", Sofía no) |

Consejo: toma al menos una captura en modo celular (F12 → ícono de dispositivo móvil)
y añádela al README como evidencia de que la aplicación funciona en pantalla pequeña.
